# Heiland2019 - NAD pathway model analysing the impact of NNMT on pathway dynamics and evolution

Tellurium-backed Biosimulant core wrapper for `MODEL1905220001`.

Scientific source of truth:
- Bundled SBML file: `data/MODEL1905220001.xml`
- Equations, parameters, units, and initial values are not manually reimplemented.

Public headline outputs:
- `namn` maps to SBML `NaMN`.
- `nam` maps to SBML `NAM`.
- `nad` maps to SBML `NAD`.

Caveat:
- Values are native SBML quantities; equations, parameters, and initial values remain in the bundled source file.
