Tellurium-backed Biosimulant core wrapper for `MODEL2306170002`.

Scientific source of truth:
- Bundled SBML file: `data/MODEL2306170002.xml`
- Equations, parameters, units, and initial values are not manually reimplemented.

Public headline outputs:
- `erk_c` maps to SBML `ERK_c`.
- `pp_mkk_erk_c` maps to SBML `PP_MKK_ERK_c`.
- `p_erk_c` maps to SBML `P_ERK_c`.

Caveat:
