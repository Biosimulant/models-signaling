# Bhattacharya2014 - A mathematical model of the sterol regulatory element binding protein 2 cholesterol biosynthesis pathway

Tellurium-backed Biosimulant core wrapper for `BIOMD0000000890`.

Scientific source of truth:
- Bundled SBML file: `data/BIOMD0000000890.xml`
- Equations, parameters, units, and initial values are not manually reimplemented.

Public headline outputs:
- `model_state_m` maps to SBML `m`.
- `model_state_h` maps to SBML `h`.
- `model_state_c` maps to SBML `c`.

Caveat:
- Values are native SBML quantities; equations, parameters, and initial values remain in the bundled source file.
